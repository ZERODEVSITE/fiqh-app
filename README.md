**فقه العبادات** تطبيق عربي متكامل يضع بين يديك **1102 مسألة فقهية** في **17 بابًا**، مدعومة بالأدلة والمصادر، مع مقارنة بين المذاهب الأربعة، ومواقيت صلاة وبوصلة قبلة تعمل دون إنترنت، وأدوات حساب وتتبّع، وويدجتس للشاشة الرئيسية.

صُمّم للمبتدئ وطالب العلم على حد سواء: بحث ذكي يفهم العربية، وقراءة صوتية، ومسارات تعلّم يومية، ومساحة خاصة مشفّرة للملاحظات والأسئلة الشخصية. **لا حساب، لا إعلانات، لا تتبّع، وكل بياناتك على جهازك.**

<h2><img src="https://api.iconify.design/lucide/hammer.svg?color=%23047857&width=30&height=30" width="30" height="30" alt="">&nbsp; البناء من المصدر</h2>

مجلد `android/` **يُولَّد تلقائيًا** من قالب Flutter الرسمي ثم تُطبَّق عليه تعديلات المشروع بسكربت، فلا حاجة لرفعه إلى المستودع.

```bash
# 1) أنشئ هيكل أندرويد وطبّق تعديلات المشروع
flutter create --platforms=android --org com.zerodev --project-name fiqh /tmp/scaffold
rm -rf android && cp -r /tmp/scaffold/android ./android
python3 tool/patch_android.py        # minSdk 21، الصلاحيات، الويدجتس، الاختصارات، أصوات الأذان

# 2) افحص سلامة البيانات (JSON، المعرّفات، حقول مقارنة المذاهب، المسارات)
python3 tool/validate_data.py

# 3) الاعتماديات والبناء
flutter pub get
python3 tool/patch_plugins.py        # إصلاح إضافات تستخدم flutter.compileSdkVersion
dart run flutter_launcher_icons
flutter build apk --release
```
